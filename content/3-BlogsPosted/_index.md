### [Blog 2 - Amazon SageMaker: AWS AI/ML and How to Optimize Without Wasting Money](3.2-Blog2/)
This blog provides cost and performance optimization strategies when using Amazon SageMaker, from leveraging Managed Spot Training to save up to 70% on costs, using Serverless Inference for low-frequency applications, to optimizing models with Neo and Quantization to double inference speed.
